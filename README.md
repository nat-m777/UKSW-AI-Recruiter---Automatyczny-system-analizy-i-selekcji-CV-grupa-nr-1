# AI Recruiter – Automatyczny system analizy i selekcji CV
Aplikacja wspierająca dział HR w procesie rekrutacji poprzez wykorzystanie modeli językowych (LLM) do automatycznej analizy, oceny oraz rankingowania aplikacji kandydatów na podstawie zdefiniowanych wymagań stanowiskowych.

## Uruchomienie lokalne
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
